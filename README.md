# Face Recognition & Detection

Advanced face detection and recognition system using modern computer vision techniques.

## Features

- Real-time face detection
- Face recognition
- Performance optimization for multiple camera streams
- Integrated pose estimation

## Project Structure

- `face_demo.py` - Main demonstration script
- `test_face_demo.py` - Test suite
- `*.ipynb` - Jupyter notebooks for exploration and demos

## Setup

```bash
pip install -r requirements.txt
```

## Usage

```bash
python face_demo.py
```
