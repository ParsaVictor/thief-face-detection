## `script_pipeline/`

A parallel, script-shaped pipeline (`face_demo.py`) exploring a different decision core:
dual crops, log-odds fusion of three cues, and a frontal gate on the *verdict* rather than on
*looking*. It has its own test suite and figure generator.

It is kept because several ideas in the current notebook came from it, and because the
figures in `../assets/` describing chirality were generated by `make_figures.py` here.

| File | Role |
|---|---|
| `face_demo.py` | The script pipeline |
| `test_face_demo.py` | Its test suite |
| `make_figures.py` | Figure generator for that pipeline |
| `phase_E_orientation.py` | Standalone orientation algorithm — the reference implementation of Phase E |
| `_build_v5.py` | Generator that produced the V5 notebook |
| `face_demo_v3_backup.py` | Snapshot before the V3 changes |
